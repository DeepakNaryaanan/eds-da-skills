# Hero Carousel

Full-width auto-rotating carousel used as the primary hero section. Each row is one slide. Slides cycle automatically and can be navigated via previous/next buttons and dot indicators.

## Default

| Hero Carousel              |                                                                                          |
|----------------------------|------------------------------------------------------------------------------------------|
| Image *(required)*         | Body *(required)*                                                                        |
| `<picture>` element — full-width slide background or foreground image | Eyebrow label (`<p>`), slide heading (`<h2>`), supporting paragraph, and CTA link (`<a>`) |

Each row is one slide. Minimum one slide required. The first slide is shown immediately on load (eager image loading for LCP).

## Variations

### Dark

| Hero Carousel (dark)       |                                                                                          |
|----------------------------|------------------------------------------------------------------------------------------|
| Image *(required)*         | Body *(required)*                                                                        |
| `<picture>` element        | Eyebrow, heading, paragraph, CTA link                                                    |

Renders with dark overlay on the image so white text is legible. Use when slide imagery is light-coloured.
