# Nav Cards

Grid of icon-backed navigation cards. Each card links to a key section of the site and displays an icon, a heading, a short description, and a CTA link. Typically used immediately below the hero to surface the site's primary navigation destinations.

## Default

| Nav Cards               |                                                                                        |
|-------------------------|----------------------------------------------------------------------------------------|
| Icon *(optional)*       | Body *(required)*                                                                      |
| `<picture>` or inline SVG icon | Heading (`<h3>` or `<h2>`), short description paragraph, CTA link (`<a>`) |

Each row is one card. The first cell is an optional icon image; the second cell holds the card heading, description, and CTA link.

## Variations

### Compact

| Nav Cards (compact)     |                                                                                        |
|-------------------------|----------------------------------------------------------------------------------------|
| Icon *(optional)*       | Body *(required)*                                                                      |
| `<picture>` or inline SVG icon | Heading, short description, CTA link                                          |

Renders cards with reduced padding and smaller type — useful when more than 6 cards are present.
